Descrição

Este projeto foi desenvolvido para a disciplina de Sistemas Distribuídos utilizando Python, CherryPy e SQLite.

O sistema implementa um serviço REST para gerenciamento de Neopets, permitindo operações CRUD sobre os pets e o gerenciamento de um segundo recurso relacionado: habilidades.

A comunicação é realizada através de requisições HTTP utilizando os verbos REST.

Tecnologias Utilizadas
Python 3
CherryPy
SQLite3
Routes
Postman (para testes)
